# תרגול אותות אקראיים ורעש

מערכת תרגול מבחנים לקורס **אותות אקראיים ורעש**. 43 מועדי בחינה מ-2004 עד 2026, כמעט 600 שאלות אמריקאיות עם נוסחאות ואיורים, בממשק עברי מלא.

**[▶ לתרגול](https://arielhone.github.io/exam-practice/)** (נדרשת סיסמה)

## מה יש בה

- **בחירת מבחן:** לפי מועד, עם חיפוש, או **הגרלה** של מבחן אקראי.
- **משוב מיידי:** אחרי כל תשובה רואים אם צדקת. סדר התשובות מעורבב בכל פעם.
- **ניווט חופשי:** פס ניווט לכל השאלות, דילוג, וסימון שאלות לחזרה 🏳️.
- **טיימר** ומעקב זמן לכל שאלה.
- **תחקיר שגיאות:** אחרי ההגשה מסננים לפי נכונות / שגויות / דולגו ועוברים עליהן.
- **מבחנים מאתגרים:** מסמנים מבחנים קשים ומקבלים מהם מבחן אקראי.
- **סטטיסטיקות:** ציונים לכל מבחן, רצף תשובות נכונות ומעקב שגיאות לכל שאלה, נשמרים בדפדפן.
- **ייצוא ל-CSV** של תוצאות המבחן.
- נוסחאות ב-LaTeX (MathJax), מצב כהה, מסך מלא וצלילים.

## מבנה

```
index.html        # כל הממשק והלוגיקה (HTML/CSS/JS בקובץ אחד)
exams_list.json   # קטלוג המועדים
exams/            # קובץ JSON לכל מועד
exams/images/     # איורים לשאלות
```

## פורמט שאלה

```json
{
  "id": "q1",
  "preamble": "טקסט פתיחה משותף (אופציונלי)",
  "question_text": "...",
  "options": ["א", "ב", "ג", "ד"],
  "correct_option_index": 0,
  "image_url": "exams/images/<exam_id>/q1.png"
}
```

נוסחאות נכתבות בתוך `<span class="math-container">$...$</span>`.

## הוספת מועד

1. ליצור `exams/exam_DD_MM_YYYY.json` לפי הפורמט.
2. להוסיף רשומה ל-`exams_list.json`:
   ```json
   { "id": "exam_DD_MM_YYYY", "title": "מועד DD.MM.YYYY", "file_path": "exams/exam_DD_MM_YYYY.json" }
   ```
